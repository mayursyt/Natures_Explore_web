# The Beauty of Nature Website

A responsive website showcasing the beauty of nature with 6 different pages.

## Pages

1. **Home (index.html)** - Main page with overview of nature's wonders
2. **Forests (forests.html)** - Dedicated to forest ecosystems and conservation
3. **Oceans (oceans.html)** - Exploring marine life and ocean mysteries
4. **Mountains (mountains.html)** - Celebrating mountain landscapes and peaks
5. **Wildlife (wildlife.html)** - Showcasing diverse animal species
6. **Gallery (gallery.html)** - Visual collection of nature photography

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern CSS**: Clean, modern styling with smooth hover effects
- **Navigation**: Easy navigation between all pages with consistent header
- **Natural Theme**: Green and blue color scheme reflecting nature
- **High-Quality Images**: Beautiful nature photography from Unsplash
- **Educational Content**: Informative descriptions about each nature topic

## Technologies Used

- HTML5 for structure
- CSS3 for styling (with Flexbox and CSS Grid)
- Google Fonts (Poppins)
- Responsive design principles

## How to View

Simply open `index.html` in any modern web browser to start exploring the website.

Works in all modern browsers including:
